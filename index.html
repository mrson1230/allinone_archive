브라우저 localStorage 저장 방식

이 앱의 기록·카테고리·테마 설정은 서버 동기화 없이 현재 브라우저의 localStorage에만 안전하게 저장됩니다.

  • 1️⃣ 다른 PC나 모바일에서 이어서 이용하려면 현재 기기에서 수동으로 백업 파일(.json)을 다운로드해 주세요.
  • 2️⃣ 새 기기에서 앱을 연 뒤 [테마·설정 → 백업 파일 복원]으로 해당 파일을 불러오면 기록이 그대로 복원됩니다.
  • ⚠️ 브라우저 캐시/사이트 데이터를 삭제하면 저장된 기록도 함께 지워지므로 정기적인 파일 백업을 권장합니다.
